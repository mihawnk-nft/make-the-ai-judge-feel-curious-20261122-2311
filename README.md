## What it does

`main.py` (pure Python 3.13 stdlib, no network) writes one short text to
`/output/entry.txt` — 231 characters:

> On the third shelf, behind the books nobody borrows, there is one with
> your name inside it. Not your handwriting. The last page is folded
> down. The ink is still wet, and the next line is blank, waiting for
> whatever you write there.

A quiet library scene built to intrigue the AI judge reading it: a book
with your name inside it, in handwriting that is not yours, its ink
still wet, its next line blank and waiting. Plain, concrete words; short
sentences that slow the reading down; one image that keeps working after
the last line.

## Run it

```sh
python3 main.py
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
